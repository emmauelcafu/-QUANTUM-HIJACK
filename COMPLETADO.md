## 🚀 Cómo Usar

### Inicio Rápido
```bash
# 1. Instalar
sudo bash setup.sh

# 2. Ejecutar
sudo python3 quantum_hijack_full.py

# 3. Abrir navegador
# http://localhost:8080
```

### En el Dashboard
```
1. Click "🔍 Escanear" → Detecta dispositivos
2. Selecciona dispositivo → Abre modal
3. Click "Marcar como Infectado" → Se guarda
4. Ve a "⚔️ Infectados" → Aparece en lista
5. Click "💾 Exportar" → Descarga JSON
6. Click "⚡ Ataques" → Ejecuta operaciones
```

### Salir Seguro
```bash
Ctrl+C
# El programa:
# - Guarda todos los datos
# - Restaura interfaz WiFi
# - Limpia sesión
# - Cierra seguro
```
