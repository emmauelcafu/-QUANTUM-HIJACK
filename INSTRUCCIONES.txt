📍 DIRECTORIO RAÍZ
───────────────────────────────────────────────────────────────

📄 quantum_hijack_full.py
   └─ Backend Flask principal
   ├─ 500+ líneas de código
   ├─ Controla todos los módulos
   ├─ APIs REST para cada función
   ├─ Ejecuta: setup, hostapd, dnsmasq, interceptor, dashboard
   └─ Puerto: 8080

📄 interceptor.py
   └─ Script capturador de credenciales
   ├─ Usa Scapy para sniffing
   ├─ Monitorea puertos: 21, 22, 80, 443, 3306, 5432, 27017
   ├─ Detecta patrones de credenciales (user, pass, email)
   ├─ Guarda en: logs/captured_credentials.json
   └─ Ejecución: sudo python3 interceptor.py

📄 dashboard_terminal.py
   └─ Mostrador en vivo en terminal
   ├─ UI en terminal con emojis
   ├─ Actualización cada 2 segundos
   ├─ Muestra: clientes, credenciales, estado
   └─ Interactivo (Q=Quit, R=Refresh, L=Logs, C=Clear)

📄 hostapd_1.conf
   └─ Configuración del Access Point falso
   ├─ Interface: wlan0mon
   ├─ SSID: CafeWiFi_Quantum
   ├─ Password: 12345678
   ├─ Modo: WPA2 (seguridad básica)
   └─ Canal: 6 (configurable)

📄 dnsmasq.conf
   └─ Configuración de DHCP + DNS spoofing
   ├─ Interface: wlan0mon
   ├─ Rango DHCP: 192.168.1.2-100
   ├─ Gateway: 192.168.1.1
   ├─ DNS: redirige todo a 192.168.1.1
   └─ Logs en: /var/log/dnsmasq.log

📄 setup.sh
   └─ Script de preparación (opcional)
   ├─ Pone interfaz en modo monitor
   ├─ Mata procesos conflictivos
   ├─ Configura IP: 192.168.1.1
   └─ Crea directorios (logs, payloads, capture)

📞 AYUDA RÁPIDA

¿Cómo cambiar SSID?
  └─ Edita quantum_hijack_full.py línea ~45:
     state['ssid'] = 'MiSSID'

¿Cómo cambiar canal WiFi?
  └─ Edita hostapd_1.conf línea ~7:
     channel=11  (cambio de 6 a 11)

¿Cómo cambiar gateway?
  └─ Edita quantum_hijack_full.py línea ~46:
     state['gateway_ip'] = '10.0.0.1'

¿Cómo ver logs en vivo?
  └─ Dashboard: 📋 Operaciones en Vivo
  └─ O: tail -f logs/operation_logs.json

¿Cómo exportar datos?
  └─ Dashboard: 💾 Exportar JSON
  └─ O: curl http://localhost:8080/api/export > datos.json
