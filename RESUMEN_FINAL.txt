📞 SOPORTE Y TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

PROBLEMA: "No se ven clientes"
SOLUCIÓN:
  1. Verifica que hostapd está corriendo: sudo ps aux | grep hostapd
  2. Aumenta potencia: sudo iw wlan0mon set txpower fixed 3000
  3. Cambia canal: edita hostapd_1.conf, channel=11

PROBLEMA: "Puerto 8080 ocupado"
SOLUCIÓN:
  1. Encuentra el proceso: sudo lsof -i :8080
  2. Mata el proceso: sudo kill -9 [PID]
  3. O cambia puerto en quantum_hijack_full.py

PROBLEMA: "Modo monitor no se activa"
SOLUCIÓN:
  1. Verifica airmon-ng: sudo apt install airmon-ng
  2. Fuerza modo monitor: sudo iw wlan0 set type monitor

PROBLEMA: "Dnsmasq no asigna IPs"
SOLUCIÓN:
  1. Verifica config: cat dnsmasq.conf
  2. Reinicia: sudo systemctl restart dnsmasq
  3. Ve logs: sudo tail -f /var/log/dnsmasq.log

PROBLEMA: "Credenciales no se capturan"
SOLUCIÓN:
  1. Verifica que interceptor está corriendo
  2. Usuario debe navegar web en el teléfono
  3. Debe intentar login en sitios (no basta navegar)

Más problemas → Consulta GUIA_FINAL.md
