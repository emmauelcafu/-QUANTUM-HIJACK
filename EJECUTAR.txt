═══════════════════════════════════════════════════════════════════════════════
 🎮 USO DEL DASHBOARD
═══════════════════════════════════════════════════════════════════════════════

Una vez abierto el dashboard en http://localhost:8080, podrás:

1. 📡 VER ESTADO DEL MONITOR
   - Estado de la interfaz WiFi
   - Modo Monitor activado/desactivado
   - IP local del servidor

2. 🖥️ ESCANEAR RED
   - Click en botón "Iniciar Escaneo"
   - Detecta todos los dispositivos en la red
   - Muestra IP, MAC address y detalles

3. ⚔️ MARCAR DISPOSITIVOS INFECTADOS
   - Click en dispositivo de la tabla
   - Botón "Marcar como Infectado"
   - Se guarda automáticamente en JSON

4. 📊 VER ESTADÍSTICAS
   - Total de dispositivos escaneados
   - Dispositivos infectados activos
   - Ataques completados

5. 💻 CONSOLA DE COMANDOS
   - Ejecutar comandos desde web
   - Historial de operaciones
   - Logs automáticos

6. ⚡ CONTROL DE ATAQUES
   - ARP Spoofing
   - DNS Hijacking
   - Packet Flooding

❌ "Error: Permission denied"
   ✅ Solución: Usar sudo

❌ "ImportError: No module named 'flask'"
   ✅ Solución: Instalar dependencias
      sudo pip3 install -r requirements.txt

❌ "Address already in use" (Puerto 8080 ocupado)
   ✅ Solución 1: Terminar proceso en puerto
      sudo lsof -i :8080
      sudo kill -9 [PID]
   ✅ Solución 2: Cambiar puerto en el código (línea ~600)
      app.run(host='0.0.0.0', port=9090, debug=False)

❌ "No wireless interface found"
   ✅ Solución: Verificar interfaz
      iwconfig
      # Busca algo como "wlan0" en la salida

❌ Dashboard no se carga en navegador
   ✅ Solución: Verificar que Flask esté corriendo
      # Debería ver "Running on http://0.0.0.0:8080"
